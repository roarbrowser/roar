Advanced

Automation: CDP port, AppleScript

Agents connect through the Chrome DevTools Protocol on 127.0.0.1:9222; any CDP client can too. Roar also has an AppleScript dictionary:

tell application "Roar"
  open url "https://example.com"
  execute javascript "document.title"
  get URL of every tab
end tell
