Roar.

An AI-first Chromium browser: a tidy sidebar for you, an MCP server for your agent. A few things are worth knowing before you start.

  1. Your AI agent drives Roar

    Roar ships an MCP server, so Claude and other agents can open tabs, read pages, click, fill forms and take screenshots in the browser you're using. Pages an agent opens show up as real tabs in your sidebar. Add it to Claude Code once:

    claude mcp add roar -- /Applications/Roar.app/Contents/Resources/roar-mcp.sh

    The dot under the settings icon shows whether agents can connect; click it to switch. Close it before a site that flags automated browsers.

  2. Everything starts at ⌘T

    One bar opens addresses, searches the web, jumps to an open tab, and finds pages from your history or archive. Type > first to run a command such as “Copy page as Markdown”.

  3. Links you copy are clean

    Copy Link Address unwraps Safe Links and drops .mcas.ms from the address, so what you send someone is the real page. Links you open are left alone.

  4. Pinned tabs sit in a grid

    Pick how many tiles fit on a row, and whether a short last row sits in the middle.

  5. Tabs you stop using get archived

    Each tab in the sidebar has a thin bar that shrinks while you ignore it. When it runs out, Roar moves the tab to Archived, where one click brings it back. Pinned tabs stay put.

  6. Your pull requests live in the sidebar

    Roar asks the GitHub CLI for your open pull requests every ten minutes, so nothing new to sign in to.

  7. Unread mail lives there too

    Roar reads Gmail’s unread inbox with the login you already have in each space, so nothing new to sign in to.

  8. Spaces keep work and home apart

    Each space has its own tabs, cookies and logins. Switch with ⌃1–⌃9 or the strip at the top of the sidebar. Press ⌘\ to put two tabs side by side.

You can change these later in Settings (⌘,).

Automation

Agents connect through the Chrome DevTools Protocol on 127.0.0.1:9222 (the MCP server above uses it; any CDP client can too). Roar also has an AppleScript dictionary.

tell application "Roar"
  open url "https://example.com"
  execute javascript "document.title"
  get URL of every tab
end tell
