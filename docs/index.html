Install

About five minutes, start to finish. Needs a Mac on macOS 13 or later; no Node.js.

  1. Download 1 min

    Get the latest DMG, open it and drag Roar onto Applications. Or use Homebrew:

    brew install --cask roarbrowser/tap/roar

  2. First open

    Roar is signed and notarized by Apple, so it opens like any app you download: macOS asks once whether to open it. Click Open.

  3. Connect your agent 1 min

    Roar's welcome page has a Connect button for Claude Code, Claude Desktop, Cursor, VS Code, Windsurf, Codex, Gemini CLI and others. Click yours, then restart that app. The server ships inside Roar and launches Roar if it isn't running (keep Allow agents to connect on).

    Set it up by hand

    The server is /Applications/Roar.app/Contents/Resources/roar-mcp, a stdio MCP server.

    Claude Code

    claude mcp add --scope user roar -- /Applications/Roar.app/Contents/Resources/roar-mcp

    Codex

    codex mcp add roar -- /Applications/Roar.app/Contents/Resources/roar-mcp

    Gemini CLI

    gemini mcp add roar /Applications/Roar.app/Contents/Resources/roar-mcp

    VS Code

    code --add-mcp '{"name":"roar","command":"/Applications/Roar.app/Contents/Resources/roar-mcp"}'

    Claude Desktop, Cursor, Windsurf and most others

    Add this to the client's MCP config: ~/Library/Application Support/Claude/claude_desktop_config.json, ~/.cursor/mcp.json or ~/.codeium/windsurf/mcp_config.json.

    {
  "mcpServers": {
    "roar": { "command": "/Applications/Roar.app/Contents/Resources/roar-mcp" }
  }
}

What's inside

What your agent gets

  • Your sessions, steerable from the sidebar. Every Claude Code session shows its project, its current step and whether it needs you. Open one (live sessions in tmux or cmux) to watch its terminal live and reply, or start a new one in any folder. + This tab sends the page you’re on to the session’s prompt.
  • Real tabs. Pages the agent opens land in your sidebar, so you can watch, take over or close them.
  • A way to reach you. notify_user and ask_user put cards in the sidebar; ask_user waits for your click.
  • One-click cut-off. Click the dot in the sidebar to block agents from the space you're in. A setting closes the CDP port entirely, without a restart.
  • Headed or headless. Let agents use the Roar you see, or a hidden headless Roar with its own profile.
  • Only where you allow. Agents reach the spaces you allow; ghost tabs are always off-limits.
  • Looks like Chrome to sites. Roar reports the Chrome brand and a real window frame, so it trips fewer bot checks.

What you get

  • A vertical sidebar with spaces. Each space has its own tabs and its own profile.
  • Pinned tabs and tab groups, plus split view for two tabs side by side.
  • Tabs that archive themselves after 6h, 12h, 1 day or 1 week, like Arc did.
  • Command bar. ⌘T to open, search tabs, history and page text.
  • Reader mode and page to Markdown. Clean articles, or copy any page as Markdown.
  • Chrome extensions. uBlock Origin Lite comes bundled.
  • Gmail and GitHub at a glance. Unread mail and your open pull requests sit in the sidebar; read, archive or open them without switching tabs.
  • Your default browser, if you like. One click in Settings, or say yes to the reminder at launch. Dismiss it for good if you'd rather not.
  • Leave Arc or Dia in one step. Your Arc spaces and pinned tabs come over on first launch; Chrome, Safari, Firefox, Edge and Dia import too.

Roar vs the rest

The Browser Company put Arc in maintenance mode in May 2025 to build Dia. If you lived in Arc, a company decided for you that your browser was done. The new AI browsers ship their own assistant and keep the source closed. Roar is the other answer: MIT licensed, no built-in assistant, and your own agent plugged in over MCP.
