Install

About five minutes, start to finish. Needs macOS 13 or later, or Windows; no Node.js.

Don't have an agent yet? Install Claude Code, Cursor or Codex first; any of them works.

  1. Download 1 min

    Get the latest DMG, open it and drag Roar onto Applications. Or use Homebrew:

    brew install --cask roarbrowser/tap/roar

  2. First open

    Roar is signed and notarized by Apple, so it opens like any app you download: macOS asks once whether to open it. Click Open.

  3. Connect your agent 1 min

    Roar's welcome page has a Connect button for Claude Code, Claude Desktop, Cursor, VS Code, Windsurf, Codex, Gemini CLI and others. Click yours, then restart that app. The server ships inside Roar and launches Roar if it isn't running (keep Allow agents to connect on).

    Set it up by hand

    The server is /Applications/Roar.app/Contents/Resources/roar-mcp, a stdio MCP server.

    Claude Code

    claude mcp add --scope user roar -- /Applications/Roar.app/Contents/Resources/roar-mcp

    Codex

    codex mcp add roar -- /Applications/Roar.app/Contents/Resources/roar-mcp

    Gemini CLI

    gemini mcp add roar /Applications/Roar.app/Contents/Resources/roar-mcp

    VS Code

    code --add-mcp '{"name":"roar","command":"/Applications/Roar.app/Contents/Resources/roar-mcp"}'

    Claude Desktop, Cursor, Windsurf and most others

    Add this to the client's MCP config: ~/Library/Application Support/Claude/claude_desktop_config.json, ~/.cursor/mcp.json or ~/.codeium/windsurf/mcp_config.json.

    {
  "mcpServers": {
    "roar": { "command": "/Applications/Roar.app/Contents/Resources/roar-mcp" }
  }
}

What's inside

What your agent gets

  • Real tabsPages your agent opens land in your sidebar. Watch, take over or close them.
  • It asks you firstCards in the sidebar; your click goes back to the agent.
  • Your sessions, beside your tabsSee each Claude Code session, reply, or send it the page you’re on.
  • Only where you allowOne click on the sidebar dot blocks the space you’re in. Ghost tabs are always off-limits.
  • Headless if you’d ratherAgents can use a hidden Roar with its own profile.

What you get

  • Spaces in a vertical sidebarEach space has its own tabs and its own logins.
  • Pinned tabs, groups and split viewTwo tabs side by side when you need them.
  • Tabs that tidy themselvesThey archive after 6 hours to a week.
  • Command bar and reader mode⌘T searches tabs, history and page text. uBlock Origin Lite is built in.
  • Leave Arc in one stepYour spaces and pinned tabs come over on first launch. Chrome, Safari, Firefox, Edge and Dia import too.

Roar vs the rest

The new AI browsers ship their own assistant and keep the source closed. Roar is the other answer: MIT licensed, no built-in assistant, and your own agent plugged in over MCP.
