# Roar brand accounts

Every account Roar owns, for agents and people picking this up later. Credentials are
**not** here: each account has an entry in the maintainer's password manager, folder
**"Roar brand"**, named `Roar brand – <service> (<handle>)`. Profile text, avatar and
voice come from [BRAND.md](BRAND.md).

Signup rules: sign up with the brand email; the persona's private details (birthday etc.)
are in the password manager entry "Roar brand – persona details"; CAPTCHAs and phone
checks are done by the maintainer; save the password to the password manager before submitting
the form; update this table when an account changes.

## Where things are used

- **Show HN, r/ArcBrowser, r/macapps:** drafts in `docs/launch/posts/`; post from the
  maintainer's established accounts, then reply from the same account.
- **X and Product Hunt:** post as Roar using the profile copy in BRAND.md.
- **MCP directories (Smithery, mcp.so, awesome-mcp-servers):** submit under the GitHub
  org or the maintainer's account; text in `docs/launch/posts/mcp-directories.md`.
