# Product Hunt

**Name:** Roar

**Tagline (≤60):** The AI-native, open-source browser your agent can drive (55)

**Description (≤260):**
A free, open-source sidebar browser for macOS with a built-in MCP server. Use spaces, split view and Chrome extensions yourself; let Claude or Cursor open real tabs, ask you questions in the sidebar, and get cut off with one click. (236)

## Maker's first comment

Hi Product Hunt, I'm the maker of Roar.

I use AI agents every day and kept running them in a separate automation browser where I wasn't logged in and couldn't see what they were doing. Roar is my answer: a sidebar browser I use myself (spaces with separate profiles, split view, command bar, reader mode, Chrome extensions with uBlock Origin Lite) that also ships an MCP server, so any MCP client can drive it.

When an agent opens a page, it shows up as a tab in your sidebar. It can leave you a note or ask you a question with buttons and wait for your answer. A dot at the bottom shows how many agents are connected, and clicking it closes the door.

It's free, MIT licensed and built on Chromium 154. It's macOS only and early, so I'd value bug reports and feature requests on GitHub: https://github.com/roarbrowser/roar
