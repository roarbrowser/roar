# Roar commercial: brief and storyboard

**Business:** Roar, a free, open-source (MIT) Chromium browser for macOS. **Buyer:** people who build with AI agents.
**Problem:** an agent can write the app, but it can't see or test it in your real browser.
**CTA:** roarbrowser.app. **Length:** 30 s, 16:9, 1920x1080 at 60 fps.
**True and shown:** a built-in MCP server and CDP port; the agent opens real tabs, clicks and drags in pages,
asks with buttons in the sidebar (`ask_user`) and reports there (`notify_user`); agents can be allowed per space.
**Real assets:** every Roar UI frame is a screenshot of a headless scratch Roar (`capture.mjs`) driven by the real roar-mcp.
**Staged:** the agent's code edits. Lion Den is a demo app (`scripts/demo/sites/lion-app`), so the film says so in its fine print.
**Never claim:** a particular agent brand, speed, security certifications, user counts, or Windows/Linux support.
**Brand:** ground #1e140c, ink #fbeedd, mane #ff9a2e, sun #ffc72c, mint #7aa898; rounded system type; the lion mark.
